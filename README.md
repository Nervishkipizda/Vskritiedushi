# Определение Социотипа

Мобильное приложение на React Native (Expo): открытый тест из восьми вопросов, свободные ответы и экран результата с гипотезой ТИМа.

## Как запустить

Нужны Node.js и приложение [Expo Go](https://expo.dev/go) на телефоне.

```bash
cd C:\Users\yuliy\Projects\opredelenie-sociotipa
npm start
```

Отсканируйте QR-код в Expo Go.

## Вход и Firebase

При запуске экран чёрный: безликая фигура и две кнопки — «Зарегистрироваться» и «Войти». Пароль и профиль (имя, почта) хранятся в Firebase Authentication и Cloud Firestore.

1. В [Firebase Console](https://console.firebase.google.com/) создайте проект и веб-приложение.
2. Включите способ входа Email/Password.
3. Создайте базу Cloud Firestore и вставьте правила из `firestore.rules`.
4. Скопируйте `.env.example` в `.env` и заполните `EXPO_PUBLIC_FIREBASE_*`.
5. Перезапустите `npm start`.

## ИИ-проверка ответов

Если задан `EXPO_PUBLIC_OPENAI_API_KEY`, свободные ответы отправляются в Chat Completions API и модель возвращает социотип, уверенность и дихотомии.

Скопируйте `.env.example` в `.env` и заполните ключ. Можно указать другой endpoint (например Groq) через `EXPO_PUBLIC_OPENAI_BASE_URL`.

Без ключа приложение всё равно работает: включён локальный анализатор по тексту.

После изменения `.env` перезапустите Expo.

## Экраны

- вход: темнота, белая фигура, регистрация и вход;
- главное меню: ячейки слева и справа, по нажатию выдвигаются и ведут в раздел;
- в каждом разделе слева сверху «вернуться назад»;
- тест со свободным бланком и экран результата.
